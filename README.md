# Elasticsearch vježba

## Pokretanje okruženja

```bash
docker compose up -d
```

Elasticsearch je dostupan na: http://localhost:9200
Kibana je dostupna na: http://localhost:5601 → Management → Dev Tools

## Struktura repozitorija

- `docker-compose.yml` — konfiguracija Elasticsearch + Kibana kontejnera
- `queries.http` — svi upiti iz koraka i zadataka s komentarima
- `ODGOVORI.md` — pisani odgovori na pitanja iz Zadataka 1, 2, 3, 5 i Završnog
- `screenshots/` — screenshotovi rezultata iz Kibane i terminala
